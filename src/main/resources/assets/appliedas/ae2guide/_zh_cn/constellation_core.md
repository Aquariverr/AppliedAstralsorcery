# 星座核心

用于制作[祭坛自动化接口](altar.md)，在**虹彩合成祭坛**合成。

<Recipe id="appliedas:constellation_core" />

按图放入分别与 **12 种星座**共鸣的水晶石或天辉水晶石，水晶属性不限。悬停查看每个位置所需的星座。

准备 **2,000 mB 星能液**和 **600 Lm 永时流明**，夜间用共振星杖启动，再向祭坛附近额外投掷 **2 个星尘**。
