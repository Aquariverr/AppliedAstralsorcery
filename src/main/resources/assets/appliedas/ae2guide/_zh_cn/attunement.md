# 虹彩共鸣祭坛

在夜晚，使用**虹彩合成祭坛**制作虹彩共鸣祭坛，使用**共振工作台**制作星座转继器。

<Recipe id="appliedas:iridescent_attunement_altar" />

制作虹彩共鸣祭坛还需 **2 B 星能液**、**600 Lm 空界流明**，并在祭坛附近额外丢入 **2 个星尘**。

<Recipe id="appliedas:constellation_relay" />

## 搭建

底座与**共鸣祭坛**相同，中央放置虹彩共鸣祭坛，周围的**炭黑大理石**上放置 **12 个星座转继器**。用**共振星杖**右键中央祭坛，按投影搭建。结构完整后才能工作。

**ME 共振星杖**潜行右键可消耗材料自动搭建；创造模式下，**共振星杖**潜行右键可直接搭建。

转继器的位置决定其星座。下表坐标相对于中央祭坛，**X 正方向为东，Z 正方向为南**。

| X | Z | 星座 |
| --- | --- | --- |
| 0 | -6 | 生息座 |
| 3 | -6 | 甲御座 |
| 6 | -3 | 攻烈座 |
| 6 | 0 | 摧灭座 |
| 6 | 3 | 动势座 |
| 3 | 6 | 圣芒座 |
| 0 | 6 | 晶金座 |
| -3 | 6 | 时钟座 |
| -6 | 3 | 南极座 |
| -6 | 0 | 牧夫座 |
| -6 | -3 | 天炉座 |
| -3 | -6 | 唤生座 |

## 共鸣

夜晚对应星座出现、中央祭坛上方无遮挡时，转继器周围会显示星图。手持未共鸣的物品（如**水晶石**或**天辉水晶石**）右键对应转继器，默认 **25 秒**完成共鸣。

也可用漏斗或管道输入。**潜行空手右键**取回原料。产物向上弹出，可用 **ME破坏面板**收集；请保持转继器上方空置。

## 棱彩流明

用 **ME输出总线**或附近的**流明丝结**向中央祭坛供应棱彩流明，存有流明时显示全部星图，并可忽略星座和天空条件进行共鸣。借助棱彩流明的共鸣每次默认消耗 **50 Lm**，完成时扣除，储量不足时暂停；全程满足星座和天空条件时不消耗流明。

祭坛容量为 **16,000 Lm**，将准星对准祭坛可查看储量。

每次消耗可在模组配置的**服务端设置 → 流明消耗**中调整。
