# 虹彩共鸣祭坛

<Recipe id="appliedas:iridescent_attunement_altar" />

合成还需 **2,000 mB 星能液、600 Lm 空界流明**，并向祭坛附近额外投掷 **2 个星尘**。

<Recipe id="appliedas:constellation_relay" />

## 搭建

沿用共鸣祭坛底座，中央换为**虹彩共鸣祭坛**，周围炭黑大理石上放置 **12 个星座转继器**。用共振星杖查看投影，或用 [ME 共振星杖](wand.md)建造。

转继器位置决定星座。坐标相对中央祭坛，**X 正方向为东，Z 正方向为南**。

| X | Z | 星座 |
| --- | --- | --- |
| 0 | -6 | 生息座 |
| 3 | -6 | 甲御座 |
| 6 | -3 | 攻烈座 |
| 6 | 0 | 摧灭座 |
| 6 | 3 | 动势座 |
| 3 | 6 | 圣芒座 |
| 0 | 6 | 晶金座 |
| -3 | 6 | 时钟座 |
| -6 | 3 | 南极座 |
| -6 | 0 | 牧夫座 |
| -6 | -3 | 天炉座 |
| -3 | -6 | 唤生座 |

## 共鸣

夜晚星座出现、中央祭坛上方无遮挡时，手持未共鸣的水晶石等物品**右键对应转继器**，默认 **25 秒**完成。

也可用漏斗或管道输入；**潜行空手右键**取回材料。产物向上弹出，可用 ME 破坏面板收集，须保持上方空置。

向中央祭坛供给**棱彩流明**可忽略星座与天空条件，每次默认消耗 **50 Lm**，完成时扣除，不足时暂停。全程满足原有条件时不消耗流明。可用 ME 输出总线或流明丝结供给，容量为 **16,000 Lm**。
