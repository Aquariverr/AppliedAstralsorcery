# 遗物

遗物的稳定条件以物品提示为准，发光颜色没有固定的对应材料。

## 如何稳定

1. 将遗物丢在地上唤醒，再拾起，悬停查看物品提示。已完成的条件会直接写出，新条件只给出线索。
2. 准备所需方块、生物或地点，再丢下遗物。它发光并鸣响时，在光芒消退前依次满足条件。**每轮先检查所有已完成的条件，最后检查一条新条件。**
3. 整轮通过后，稍等片刻再拾起查看下一条提示，补齐材料，再继续。直到物品状态显示**“稳定”**，即可保存或用于合成。

发光期间无法拾取；需要更换地点时，等这一轮结束再收回。多次失败可能使遗物更不稳定，甚至毁掉遗物。它还可能召唤怪物、自行移动或传送；满足条件可以改善稳定状态。

## 条件对照

以下为默认条件。方块要**放置在遗物旁**，丢出物品无效；生物也要靠近遗物。方块数量按占用的格数计算，同一格中的多支蜡烛只算一格。

### 方块

| 提示中的线索 | 放置的方块 |
| --- | --- |
| 沉重的锻台 | 1 个铁砧 |
| 安静的观察者 | 1 个侦测器 |
| 声音方块 | 1 个唱片机、钟或音符盒 |
| 能做地图的 | 1 个制图台 |
| 对声音敏感的方块 | 1 个幽匿感测体 |
| 生物笼子 | 1 个刷怪笼或试炼刷怪笼 |
| 飘动的装饰布料 | 1 面旗帜 |
| 紫色的水晶 | 2 个紫晶芽或紫水晶簇 |
| 充满生机的礁石方块 | 2 个珊瑚块 |
| 寒冷清澈的方块 | 2 个冰方块 |
| 矿藏 | 2 个矿石方块 |
| 珍贵的宝石块 | 2 个钻石块或绿宝石块 |
| 信号组件 | 2 个红石线、红石火把、中继器、比较器或阳光探测器 |
| 纠缠的网 | 3 个蜘蛛网 |
| 蜡质光源 | 3 个蜡烛方块 |
| 爆炸物 | 3 个未点燃的 TNT 方块 |
| 盛开的枝叶 | 4 个花朵方块 |
| 树叶 | 4 个树叶方块 |
| 树木的主干 | 4 个原木 |

花朵、树叶和原木可能被消耗，下一轮前补齐数量。

### 生物、伤害与地点

| 提示中的线索 | 做法 |
| --- | --- |
| 水生生物 | 带来 2 只水生生物 |
| 骷髅生物 | 带来 2 只骷髅 |
| 拥有血肉的亡灵怪物 | 带来 2 只僵尸 |
| 袭击的一部分 | 带来 2 名掠夺者 |
| 锋刃 | 用剑攻击遗物 |
| 被射击 | 用箭等弹射物击中遗物 |
| 被点燃 | 让遗物受到火焰伤害 |
| 被炸 | 让遗物受到爆炸伤害 |
| 深渊之地的虚空 | 将遗物带到末地，再丢下 |
| 地狱之地的灼热 | 将遗物带到下界，再丢下 |
| 可怕的要塞 | 在下界要塞内丢下遗物 |
| 地下的要塞 | 在主世界要塞内丢下遗物 |
| 废弃的矿区 | 在废弃矿井内丢下遗物 |

## 用途

稳定遗物可用于制作[祭坛自动化接口](altar.md)。用[自动星辉金属凿子](chisel.md)加工遗物可获得碎片，但可能消耗遗物。任意种类的遗物碎片都可用于[容量强化](enhancement.md)。
