# ME 流明阵列

从 ME 网络补充原料和流明，为附近设备供能或将产出的流明存回网络。

<Recipe id="appliedas:me_lumen_array" />

合成时还需向共振工作台附近投掷 **2 颗海蓝宝石**。

## 使用

1. 从**底部**连接 ME 网络，供电并提供一个频道。
2. 用界面箭头选择流明，在 ME 中准备星能液和对应催化剂，开启**自动补给**。
3. 设置**保留量**（0–4,000 Lm）：不足时从 ME 补充；开启**回存网络**后，超出部分存回 ME。设为 0 可存回全部产出。

**红石控制**开启后，生产需要红石信号，ME 补给和回存不受影响。**丝结交互**开启后，允许 ME 流明丝结抽取；两项默认关闭。

切换流明前会将旧流明和催化剂存回 ME。停在“切换中”时，检查网络和存储空间。
