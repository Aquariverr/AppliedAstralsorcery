# Constellation Core

Crafted on an **Iridescent Crafting Altar** for the [Altar Automation Interface](altar.md).

<Recipe id="appliedas:constellation_core" />

Use Rock or Celestial Crystals attuned to **all 12 constellations** in the shown positions. Crystal attributes do not matter. Hover over each crystal to see the required constellation.

Supply **2,000 mB Liquid Starlight** and **600 Lm of Aion**. Start at night with a Resonating Wand, then drop **2 additional Stardust** near the altar.
