# Artifacts

Read an artifact's item tooltip for its conditions. Glow colors do not correspond to fixed materials.

## How to stabilize an artifact

1. Drop the artifact to wake it, then pick it up and read its tooltip. Completed conditions are stated directly; the new condition gives a clue.
2. Prepare the required blocks, creatures or location, then drop it again. When it glows and rings, meet each condition before its light fades. **Each round checks all completed conditions in order, followed by one new condition.**
3. After passing the whole round, wait briefly before picking it up to read the next clue, replenish materials and continue. Once its status reads **Stable**, you can store it or use it in crafting.

You cannot pick it up while it glows. Wait until the round ends before collecting it to move elsewhere. Repeated failures may make it less stable or even destroy it. It may also summon mobs, move or teleport; meeting conditions can improve its stability.

## Condition reference

These are the default conditions. **Place blocks beside the artifact**; dropped items do not count. Bring creatures close to it as well. Block counts refer to occupied positions: several candles in one block count as one.

### Blocks

| Clue | Blocks to place |
| --- | --- |
| Heavy forge | 1 Anvil |
| Quiet watcher | 1 Observer |
| Sound blocks | 1 Jukebox, Bell or Note Block |
| Map maker | 1 Cartography Table |
| Sound sensitive block | 1 Sculk Sensor |
| Mob cage | 1 Spawner or Trial Spawner |
| Decorated waving cloth | 1 Banner |
| Purple crystals | 2 Amethyst Buds or Amethyst Clusters |
| Vibrant reef blocks | 2 Coral Blocks |
| Cold clear blocks | 2 Ice blocks |
| Mineral deposits | 2 Ore blocks |
| Precious gem blocks | 2 Diamond Blocks or Emerald Blocks |
| Signal components | 2 Redstone Wire, Redstone Torches, Repeaters, Comparators or Daylight Detectors |
| Tangled webs | 3 Cobwebs |
| Wax lights | Candles in 3 separate blocks |
| Explosives | 3 unprimed TNT blocks |
| Blooming foliage | 4 Flower blocks |
| Tree foliage | 4 Leaf blocks |
| Wooden trunks | 4 Logs |

Flowers, leaves and logs may be consumed. Replace them before the next round.

### Creatures, damage and locations

| Clue | Action |
| --- | --- |
| Aquatic creatures | Bring 2 aquatic creatures |
| Skeletal creatures | Bring 2 Skeletons |
| Fleshy undead monsters | Bring 2 Zombies |
| Part of a raid | Bring 2 Pillagers |
| Sharp edge | Hit the artifact with a sword |
| Shot | Hit the artifact with an arrow or another projectile |
| Burned | Deal fire damage to the artifact |
| Exploded | Deal explosion damage to the artifact |
| Void of an abyssal place | Take the artifact to the End and drop it |
| Heat of an infernal place | Take the artifact to the Nether and drop it |
| Terrible fortress | Drop the artifact inside a Nether Fortress |
| Underground fortress | Drop the artifact inside an Overworld Stronghold |
| Abandoned mining area | Drop the artifact inside a Mineshaft |

## Uses

Stable artifacts are used for [capacity enhancement](enhancement.md) and crafting an [Altar Automation Interface](altar.md). An [Automatic Starmetal Chisel](chisel.md) produces shards from artifacts, but may consume the artifact.
