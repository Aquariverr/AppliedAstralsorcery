# ME Lumen Array

Refills materials and lumen from ME to supply nearby devices or store its production in the network.

<Recipe id="appliedas:me_lumen_array" />

Crafting also requires **2 Aquamarines dropped near the Resonating Crafting Table**.

## Usage

1. Connect ME to the **bottom**, with power and one channel.
2. Select a lumen type with the screen's arrows. Stock ME with Liquid Starlight and a matching catalyst, then enable **Resupply**.
3. Set the **reserve** (0–4,000 Lm). ME replenishes any shortage; **Export** returns the surplus. Set the reserve to 0 to store all production in ME.

Enable **Redstone** to require a signal for production; ME refills and exports still work. Enable **Filaments** to let ME Lumen Filaments collect the output. Both switches default to off.

Changing type first returns the old lumen and catalyst to ME. If switching stalls, check network access and storage space.
