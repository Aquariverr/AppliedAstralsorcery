# ME Lumen Filament

Collects a selected lumen type from nearby Lumen Arrays and stores it in ME.

<Recipe id="appliedas:me_lumen_filament" />

## Usage

1. Connect to a powered ME network with one channel and free lumen storage.
2. **Right-click** to open the screen and select a lumen type. Use the page buttons or scroll wheel to browse.
3. Supply that lumen in a nearby array. Each connection must be within **16 blocks** and unobstructed. Ordinary Lumen Filaments can extend the route.

Collects up to **500 Lm per second**. **Stop requests** pauses collection; lumen already received still enters ME when space is available.
