# ME Lumen Crystal Collection Plane

Install the plane on an ME cable, facing a Lumen Crystal Cluster in the adjacent block. The network needs power, an available channel and space for the harvested items. No configuration is needed.

The plane harvests one growth stage at a time, storing the crystals in ME and **leaving the smallest stage intact**. It pauses when the network cannot accept the items.

Point an [ME Lumen Crystallizer](lumen_crystallizer.md) at the same cluster from another side, configured for the cluster's lumen type. It can regrow the cluster using lumen from ME without consuming another catalyst.
