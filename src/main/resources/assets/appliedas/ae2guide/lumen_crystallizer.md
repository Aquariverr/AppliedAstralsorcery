# ME Lumen Crystallizer

1. Install the panel on an ME cable and leave the block directly in front clear. The network needs power and an available channel.
2. **Right-click with a crystallization catalyst** to select it. This does not consume the held item. **Sneak-right-click with an empty hand** to clear the selection.
3. Store the selected catalyst and the recipe's lumen type in ME. The panel uses them to form and grow a Lumen Crystal Cluster in front; it does not require Liquid Starlight. Catalysts may shatter before a cluster forms, and growth time varies.

Changing or clearing the selection takes effect after the current cluster finishes growing. Harvest the mature cluster by hand, or use an [ME Lumen Crystal Collection Plane](lumen_crystal_collector.md) for automatic collection.
