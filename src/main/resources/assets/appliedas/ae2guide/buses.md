# Transferring Lumen with Buses

Mount the bus against the **bottom** of a Lumen Array and connect it to a powered ME network with an available channel.

| Bus | Purpose |
| --- | --- |
| ME Import Bus | Move lumen from the array into ME |
| ME Export Bus | Supply the array with selected lumen from ME |
| ME Storage Bus | Access lumen stored in the array through ME terminals |

## Filters

Open the bus screen, pick up the corresponding Lumen Crystal with your cursor, then **right-click a filter slot** to select its lumen. Left-click selects the crystal item. Setting a filter does not consume the crystal; Export Buses require a filter.

Arrays stop allowing extraction below **2,000 Lm**. The destination needs free storage. Import and Export Buses accept Acceleration Cards.
